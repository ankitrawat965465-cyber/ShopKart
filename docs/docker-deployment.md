🚀 My DevOps Journey: Running a Flask Application with Docker 🐳

Today, I practiced Docker hands-on by running my ShopKart Flask application inside a Docker container.

As a DevOps fresher, Im learning how Docker helps developers package and run applications consistently across different environments.

🛠️ What I practiced:

✅ Pulled a Docker image from Docker Hub
✅ Ran a container using docker run
✅ Configured port mapping (8080:8080)
✅ Verified the running container using docker ps
✅ Checked application logs using docker logs
✅ Practiced container lifecycle commands: stop, start and restart
✅ Verified that my application returned HTTP 200 OK

💻 Command used:docker run -d --name shopkart-container -p 8080:8080 ghurka/shopkart:1.0

🎯 Key learnings:
🔹 Image = Template used to create containers
🔹 Container = Running instance of an image
🔹 Port mapping = Makes the containerized application accessible from the host
🔹 Logs = Help troubleshoot application issues

📌 Next on my learning roadmap: Docker Compose, GitHub Actions CI/CD, Kubernetes and Argo CD.

I believe consistent hands-on practice is the key to becoming a better DevOps Engineer.Small steps every day, big goals ahead! 🚀
